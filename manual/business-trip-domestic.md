# 国内出張申請の書き方

国内の出張（他拠点訪問、客先訪問、社内イベント参加など）にかかる旅費・宿泊費等を申請するための手続きです。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで「出張申請」を選びます。
3. タイトル・出発地・到着地・開始日・終了日・説明を入力します。日数は開始日と終了日から自動計算されます。
4. 出発地・到着地を選択すると、概算出張費が自動的に算出され、金額欄にセットされます。
5. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 出張の目的が分かる短い名称（例: 大阪拠点 定例会議出席） |
| 出発地 / 到着地 | 出張の移動元・移動先の都市 |
| 概算出張費 | 出発地・到着地から自動的に算出される金額（手入力はできません） |
| 開始日 / 終了日 | 出張の初日と最終日（日帰りの場合は同日を指定） |
| 日数 | 開始日・終了日から自動計算される出張日数 |
| 説明 | 出張先・目的・訪問先などの詳細 |

## 概算出張費の算出について

概算出張費は、社外の提携サービスが算出しています。提携サービス側のパフォーマンスが徐々に低下しており、稀に算出に失敗することがあります。失敗した場合は金額欄にエラーが表示され、そのままでは申請できません。その場合は、New Relic（監視ツール）で事象を確認し、対処してください。

## 承認について

出張申請は、直属の上司（マネージャー）による承認を経て確定します。承認完了後、内容の変更はできないため、日程や目的地に誤りがないか事前によく確認してください。

## 申請時の注意点

- 日程が確定してから申請してください。仮の日程で申請すると、後の変更対応に時間がかかります。
- 出張先での予定（訪問先・面談相手など）が分かる場合は、説明欄に記載しておくと承認がスムーズです。
- 日帰り出張の場合も、通常の出張申請と同じ手順で申請できます。
