# プロモーション申請の書き方

メンバーの昇進（プロモーション）を上長が申請するための手続きです。プロモーション申請は、上長（マネージャー）のみが行えます。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで「プロモーション申請」を選びます。
3. タイトル・説明を入力します。
4. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 対象者の昇進が分かる短い名称（例: 山田太郎氏 プロモーション申請） |
| 説明 | 下記テンプレートに従って記載してください |

## description（説明欄）の書式

説明欄は、以下のテンプレートに沿って、先頭にまとめて記載してください。

```
対象者：(対象者のメールアドレス)
内容：プロモーション：(現在の等級)から(昇進後の等級)
```

**記載例**:

```
対象者：yamada.taro@learn.nrkk.technology
内容：プロモーション：L3からL4

現職でのプロジェクトマネジメント実績、技術リード経験を評価し、昇進を申請します。
```

## 承認について

プロモーション申請は、社内の承認フローに従って処理されます。承認が完了すると、対象者の等級変更が確定します。

## トラブルシューティング

申請時にエラーが発生し、原因が分からない場合は、New RelicのUI上でAI（Autopilot）に質問してみてください。

本申請の調査用に、ナレッジベース「Workflow Promotion Trouble Shoot」が用意されています。New RelicのAIチャット画面で `/` を入力するとナレッジベースの一覧が表示されるので、その中から「Workflow Promotion Trouble Shoot」を選択したうえで、発生している内容を質問してください。
