# 海外出張申請の書き方

海外拠点への訪問、海外カンファレンスへの参加、海外の取引先との商談などにかかる旅費・宿泊費等を申請するための手続きです。基本的な申請手順は国内出張申請と同じです。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで「出張申請」を選びます（国内・海外で申請タイプは分かれていません）。
3. タイトル・開始日・終了日・説明を入力します。日数は開始日と終了日から自動計算されます。
4. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 出張の目的が分かる短い名称（例: ロンドン拠点 技術カンファレンス参加） |
| 開始日 / 終了日 | 出発日と帰国日 |
| 日数 | 開始日・終了日から自動計算される出張日数 |
| 説明 | 訪問先の国・都市、目的、同行者などの詳細 |

## 承認について

海外出張申請も、直属の上司（マネージャー）による承認を経て確定します。ビザの取得や航空券の手配など、準備に時間がかかる項目が多いため、余裕を持ったスケジュールで申請することをおすすめします。

## 申請時の注意点

- 出発日までの準備期間（ビザ取得、予防接種、航空券・宿泊の手配など）を考慮し、早めに申請してください。
- 申請フォームには、出発日までの日数に関する表示が案内として表示される場合があります。
- 出張後に発生する経費（航空券代、宿泊費など）は、別途「経費精算」の手続きが必要です。詳しくは経費精算のマニュアルを参照してください。
