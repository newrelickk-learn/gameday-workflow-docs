# 経費申請の書き方

日常的な業務に必要な費用を会社に申請するための手続きです。備品購入、ツールの利用料、書籍購入費など、業務に必要な経費全般が対象になります。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで「経費申請」を選びます。
3. タイトル・金額・説明を入力します。
4. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 何のための経費かが一目で分かる短い名称（例: 開発用モニター購入） |
| 金額 | 実際に支払った、または支払う予定の金額（円） |
| 説明 | 用途・利用目的・見積内容など、承認者が判断できる情報を記載 |

## 承認について

- 少額の経費は自動承認、または承認不要のラインが設けられています。
- 一定額を超える申請は、直属の上司（マネージャー）の承認が必要になります。
- 承認者が明確に決まらない場合、申請がエラーになることがあります。その場合は人事・総務担当に問い合わせてください。

## よくある記載ミス

- タイトルが「経費申請」など汎用的すぎて、内容が分からない。
- 説明欄が空欄、または一言だけで、承認者が判断できない。
- 金額の単位や桁を誤って入力している。

申請前に一度、承認者の立場から見て内容が十分かどうかを確認しましょう。
