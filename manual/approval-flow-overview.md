# 承認フロー全体の概要

社内の各種申請は、申請タイプに応じて異なる承認フローで処理されます。ここでは全体像を紹介します。

## 承認の基本的な考え方

1. 申請者が申請を作成すると、申請内容とルールに基づいて承認者（承認ステップ）が自動的に決定されます。
2. 承認者に「承認依頼」の通知が送られます。
3. 承認者が承認・却下を判断します。
4. 複数ステップの承認フローの場合、あるステップの承認が完了すると、次のステップの承認者に通知が送られます。
5. すべてのステップの承認が完了すると、申請のステータスが「承認済み」になります。いずれかのステップで却下されると「却下」になります。

## 承認ステップ数の目安

| 申請タイプ | 承認ステップ数の目安 |
| --- | --- |
| 経費申請 | 1段階（直属マネージャー） |
| 出張申請（国内・海外） | 1段階（直属マネージャー） |
| 経費精算 | 金額により1段階または2段階（マネージャー→経理部） |
| プロモーション申請 | 社内規定に基づく承認フロー |

## ステータスの見方

申請一覧画面では、以下の情報を確認できます。

- **ステータス**: 承認待ち／承認済み／却下
- **承認ステップ**: 現在何ステップ目か／全体で何ステップあるか
- **次の承認者**: 現時点で承認待ちになっている担当者

進行状況を確認したいときは、まずこの申請一覧画面をチェックしましょう。
