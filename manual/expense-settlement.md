# 経費精算の書き方

出張や業務で発生した費用（航空券代、宿泊費、交通費、会食費など）を、実際に支払った金額に基づいて精算するための手続きです。日常的な備品購入などの「経費申請」とは別の手続きとして扱われます。

## 申請の流れ

1. ダッシュボードの「申請一覧」から「新規申請」を選択します。
2. 申請タイプで経費に関する申請を選びます。
3. タイトル・金額・説明を入力します。
4. 内容を確認し、申請を確定します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| タイトル | 何の精算かが分かる短い名称（例: 海外出張 航空券・宿泊費精算） |
| 金額 | 実際に支払った合計金額（円） |
| 説明 | 内訳（航空券代・宿泊費・交通費など）、関連する出張・出来事の内容 |

## 承認フローについて（金額による違い）

経費精算の承認フローは、金額規模に応じて段階が異なります。

- **一定額を超えない精算**: 直属の上司（マネージャー）の承認のみで完了します。
- **一定額を超える精算**（航空券代・宿泊費など、海外出張に伴う精算のように高額になりやすいもの）: 社内規定により、「直属マネージャーの承認」に加えて「経理部の承認」の2段階の承認が必要になります。マネージャーの承認が完了した後、続けて経理部の承認が行われて初めて精算が完了します。

このため、高額な経費精算は少額の経費申請よりも承認完了までに時間がかかることがあります。マネージャーの承認が済んでいても、経理部の承認が終わるまでは申請は「承認待ち」のままです。あらかじめこの2段階の流れを理解しておくと、進行状況を正しく把握しやすくなります。

## 申請時の注意点

- 支払いを証明できる情報（レシート・請求書の内容など）は説明欄に整理して記載しておくと、承認がスムーズです。
- 内訳が複数ある場合は、費目ごとに金額を分けて記載すると承認者が確認しやすくなります。
